# Kitchen Inventory Management TUI

## Why this even started?

Searched many inventory system to self-host to keep my kitchen organized and to know what items I should use before expiry dates.

I didn't find any specific or general inventory management system simple enough to tell me the dates properly. All others give importance to the value of the stock like in a business. So, All I want is a simple TUI (for now) based application to log items with its expiry dates and more. Then check the items which are going to expiry as easy as possible.

Definitely not.
